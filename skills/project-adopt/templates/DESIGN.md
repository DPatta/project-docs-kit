# Design — {{PROJECT_NAME}}

The look and feel of the user interface. `design-ui/tokens.css` holds every value and this file
explains them. Approved mockups are listed under Screens.

## Files

- `design-ui/tokens.css` — the single source of every color, font, spacing and radius value
  (light and dark)
- `design-ui/proposals/` — HTML mockups, plus an index.html that compares them once there are
  several
- `design-ui/README.md` — what each file in `design-ui/` is and when to use it

Rules:
- A token change updates `design-ui/tokens.css`, every theme file derived from it (e.g. a UI
  library theme) and this file, in the same change.
- Proposals that were not chosen stay in `design-ui/proposals/`, marked "superseded" at the top
  of the file and in `index.html`.
- A new screen is built only from a mockup listed under Screens.
